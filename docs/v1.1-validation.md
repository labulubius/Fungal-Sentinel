# Fungal Sentinel v1.1 validation

## Automated checks

Run:

```bash
./gradlew testDebugUnitTest lintDebug assembleRelease
```

The unit suite checks B/R wavelength fitting with G hold-out error reporting, ascending wavelength ordering for a negative pixel/nm slope, positive trapezoidal integration, SPD CSV/default-SPD handling, and concentration regression.

## Device acceptance checklist

Use a Camera2 device exposing `MANUAL_SENSOR` and `RAW`.

1. Install v1.1 over v1.0 with the same signing key and confirm the app starts.
2. Confirm preview, ISO, exposure, focus, white balance, noise reduction, edge and hot-pixel controls still work.
3. Capture a normal DNG and inspect it with `exiftool`.
4. Open **Analyze** and complete Step 1 with the R/G/B positioning source.
   - Verify all three profiles are visible.
   - Verify the mapping and numeric G validation error are shown.
5. Optionally import a two-column SPD CSV, then complete Step 2.
   - If omitted, verify the workflow uses the FSSA simulated default SPD.
   - Verify three finite response curves are shown over 420–680 nm.
6. Select a fluorophore and complete Step 3.
   - Verify area and peak are non-negative and repeat analysis is stable.
7. Capture 2–5 standards and calculate Step 4.
   - Verify equation, R², predicted concentration, and out-of-range indication.
8. Confirm DNG files appear under `Pictures/FungalSentinel` with `positioning_`, `spd_`, `sample_`, or `standard_` prefixes.

## Input-error checks

- Import malformed SPD data: the app reports an error and does not crash.
- Use identical standard concentrations: regression is rejected.
- Predict outside the standards' range: an extrapolation indication is shown.
- Switch SPD input or fluorophore: incompatible downstream results are cleared.

## Interpretation

Like `FSSA_v1.3.2.py`, the G residual is reported for the user rather than used as a hard workflow gate. A normal photograph can therefore produce a numerical calibration, but that result is not scientifically meaningful. Formal measurements require the matching positioning source, standard light source, optical hardware, stable camera settings, validated standards, and biological reference measurements.
