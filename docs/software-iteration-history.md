# Fungal Sentinel 软件迭代记录（Git 证据与队员回忆）

本文件供整理 Wiki 的 Software / Engineering 页面使用。**Git 提交能确认代码变化，不足以独立证明修改的起因或科学性能；队员回忆标注为回忆，不等同于完整测试报告。**下列时间是提交日期（2026 年），并非所有设计讨论的发生日期。本文件也不代替各版本的历史交接文档。

## 6 月：从手机 RAW/DNG 捕获开始

- **代码**：初版 Android App 与 DNG 拍摄流程，之后增加相机准备状态检查（`b7578a5`、`4529fb4`）。
- **贺嘉淇回忆**：当时是约 v1.0 阶段，已能拍摄原生 DNG。暑期，侯天楠和张之确一起设计并迭代 FSSA 算法。
- **写作边界**：这里的“共同设计”来自队员回忆；两人的具体贡献分工及算法版本需与本人核对，不应仅由 Android 仓库提交推定。

## 9 月初（2–3 日）：接入 FSSA 分析

- **代码**：增加设备端光谱分析和分步骤采集流程（`24881cd`、`ccedd17`）；后续清除失效校准、对齐当时的 Python 参考流程（`989fa4d`、`d5e93bc`）。
- **贺嘉淇回忆**：将侯天楠的 FSSA 模块吸纳进 Android 软件。
- **写作边界**：这证明从 DNG 捕获逐步发展到设备端分析，但不能据此宣称 Android 与 Python 已完成真实数据的数值一致性验证。

## 9 月中旬（10–12 日）：界面、数据来源及分析流程

- **贺嘉淇回忆**：组会后吸收了多项意见，包括让设置仅占屏幕一部分、保留拍摄画面，以及接入新的 FSSA v1.3.4；参考数据通过 CSV 导入。另有“某个图看不明白，后来调整了”的印象，但具体是哪张图和如何调整已无法确认。
- **界面代码**：由叠层控件改为目录侧边栏（`080e579`），随后迭代紧凑/窄屏布局（`59107b2` 等）。当前 `SidebarPanel.kt` 使用 56 dp 紧凑目录栏和至多 360 dp 的详情面板，在打开设置等详情时保留可见预览。**已实现限宽界面，不保证任何手机上严格 50% 占比**；可手动切换的专用半屏模式是另一个尚未确定的附加需求。
- **参考数据代码**：Step 3 响应校准支持导入与标准光源匹配的自定义 SPD CSV，并可恢复内置 SPD（`4001abe`，`FssaPanel.kt`）。CSV 在这里是**光谱功率分布数据**，不能笼统写成可导入任意实验结果。内置 SPD 的完整光源溯源仍待补充。
- **图表代码**：`81dacec` 用波长坐标改进 Response / Sample 图，加入坐标轴、目标峰与积分区间标注，并加入浓度图；`0d346ed` 将定位图改为使用定位批次平均 profile。**尚无证据确定队员提到的模糊图表反馈对应哪张图，也不能说某图“换回旧版”**。
- **其他代码**：`d92c89f` 检查分析捕获的参数一致性；`0d346ed` 实现与 Python FSSA v1.3.4 对齐的多帧采集、背景扣除、积分和标准曲线等核心流程。相机资源保护也持续迭代（`94e8117`、`5399646`），但不能未经确认就归因为实际硬件故障。

- **贺嘉淇回忆**：后期自己遇到并修复过一些 bug；目前未明确表示这条自动曝光问题是否就是其中之一，因此不将具体问题的发现人写死。

## Wiki 写作与后续核实

可以写已经实现的**软件设计和迭代**，也可以说明组会反馈；不要把 Git 修改直接当成硬件实验结果。当前没有提供可用于 Wiki 的完整真机测量数据，不写准确率、检出限、实地效果或与 Python 的数值等效性结论。尚待核对的事项：FSSA 合作分工、特定图表反馈的对象、后期具体 bug，以及硬件修改与软件修改之间的真实对应关系。
