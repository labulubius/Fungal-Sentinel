## 当前验证基线

最近一次检查结果：

- `testDebugUnitTest`：11 项测试通过，0 失败；
- `lintDebug`：0 错误，28 个非阻塞警告；

- 模拟器中预览、菜单、横竖屏布局、目录滚动、RAW 捕获和分析流程可以运行；
- 未发现 App 崩溃或 ANR。

模拟器限制：

- 虚拟后置相机声明支持 RAW，但不支持 `MANUAL_SENSOR`，因此不能验证手动曝光和 ISO；
- 虚拟相机缺少 `BaselineExposure` 元数据，Android `DngCreator` 无法生成有效 DNG；
- 模拟器可以用于验证 RAW 数据返回和分析流程，但 DNG 保存及光谱准确性必须在真机验证。

## P0：下一步优先处理

### 1. 修复横竖屏切换后的相机预览方向

**状态：已完成，待真机复核。**

模拟器复查未重现画面横置，但确认旧实现直接用视图宽高作为相机缓冲区尺寸，导致竖屏预览比例明显拉伸。现已根据显示旋转、传感器方向和摄像头朝向选择受支持的预览尺寸，并为 `TextureView` 设置居中裁切变换；表面尺寸变化时会重新计算。

**要求：**

- 根据显示旋转、传感器方向和前后摄方向计算预览变换；
- 横屏和竖屏切换后保持画面方向正确；
- 保持合理的中心裁切比例，避免拉伸；
- 不破坏 Camera2 暂停/恢复和 RAW 拍摄生命周期。

**验收：** 竖屏 → 横屏 → 竖屏重复切换多次，预览方向、比例和拍摄均正常，无需重启 App。

模拟器已完成正反横竖屏及连续六次切换检查，画面方向和比例正常，未出现崩溃或相机会话错误；不同传感器方向仍需在真机复核。

### 2. 真机 Camera2/RAW/DNG 验证

**状态：待具备支持 RAW 的真机后执行。**

至少验证：

- DNG 文件可正常保存并被常见软件读取；
- 400 ms 曝光、ISO、无穷远焦距实际生效；
- 自动曝光模式和部分能力降级逻辑正确；
- 暂停/恢复、锁屏返回和连续拍摄不闪退；
- 样品、标准品和校准拍摄使用一致的参数和元数据。

## 实施与回滚规则

每次只处理一个小项目：

1. 修改前检查 Git 工作区，避免覆盖现有未提交内容；
2. 只修改当前项目所需文件；
3. 运行相关单元测试、编译检查和可执行的模拟器/真机验证；
4. 测试通过后创建独立 Git commit；
5. 在结果中记录提交哈希和验证方式；
6. 需要撤销时优先使用 `git revert <commit>`，保留完整历史。
