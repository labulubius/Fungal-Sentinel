# Fungal Sentinel 下一版本改进计划

本文档整理自 `group/new version sheet.txt`、当前 Android 实现检查结果及开发讨论。每个项目应作为独立的小修改完成，并在测试通过后建立单独的 Git 提交，以便安全回滚。

## 已完成

### 1. 自动选择后置摄像头

- 不再将 Camera ID 固定为 `"0"`。
- 启动时从系统公开的摄像头列表中选择后置摄像头。
- 避免模拟器或部分真机因不存在 Camera ID `"0"` 而闪退。
- 对应提交：`df805b0 fix: select primary back-facing camera`

## P0：界面与结果显示

### 2. 全面屏与系统安全区域适配

**问题：** Analyze、设置和底部拍摄按钮距离屏幕边缘过近，可能被状态栏、导航栏、刘海或挖孔遮挡。

**要求：**

- 摄像头预览可以继续延伸至整个屏幕。
- 所有非摄像头预览内容必须避开系统安全区域。
- Analyze、设置、Save DNG 和分析面板应适配状态栏、导航栏、刘海及前摄挖孔。
- 横屏、竖屏和不同屏幕比例下均应可操作。

**验收：** 在普通屏、挖孔屏以及启用手势导航的模拟设备或真机上，任何操作控件都不被系统 UI 遮挡。

### 3. 放大 Analyze 与设置按钮

**要求：**

- 增大按钮的视觉尺寸和点击区域。
- 设置按钮使用清晰的图标，而不是尺寸较小的文本符号。
- 按钮与安全区域边缘保持合理间距。

**验收：** 两个按钮均容易点击，且不会紧贴屏幕边缘。

### 4. 修复 Sample Analysis 图表

**现有问题：** 当前图表横坐标按数组下标绘制，没有使用样品分析结果中的真实波长 `wavelengthsNm`。

**要求：**

- 使用真实波长作为横坐标。
- 使用修正后的光谱强度作为纵坐标。
- 显示坐标轴名称、刻度和单位。
- 仅显示有效波长范围，避免无效数据影响缩放。
- 标出所选荧光蛋白的目标峰值波长及积分区间。
- 对空数据、常数数据和异常值进行安全处理。

**验收：** 图表中的曲线位置与真实波长一致，目标峰和积分范围清晰可见。

### 5. 增加 Concentration 图表

**要求：**

- 绘制标准品浓度与荧光积分面积散点。
- 绘制线性回归拟合线。
- 标出未知样品的预测点。
- 显示浓度和荧光积分面积坐标轴。
- 在图表附近显示拟合公式和 R²。
- 当预测浓度超出标定范围时，显示明显警告。

**验收：** 完成浓度计算后，用户可以直观看到标准曲线、拟合质量和样品位置。

## P1：摄像参数

### 6. 默认曝光时间改为 400 ms

**要求：**

- 手动模式默认曝光时间设置为 `400 ms`（`400,000,000 ns`）。
- 若设备不支持 400 ms，自动限制到设备公开的有效范围。
- UI 显示设备实际采用的曝光值，而不是未经限制的目标值。

**验收：** 支持 400 ms 的设备默认显示并使用 400 ms；不支持的设备不会崩溃，并显示限制后的值。

### 7. 改进曝光调节标尺

**问题：** 当前曝光滑杆采用大范围线性映射，短曝光区域难以精确调整。

**要求：**

- 使用对数刻度、分段刻度或其他适合大动态范围的映射。
- 显示清楚的曝光时间及单位。
- 允许用户精确设置常用曝光值，包括 400 ms。

**验收：** 用户可以稳定、准确地调到常用曝光值，不会因滑杆范围过大而难以操作。

### 8. 独立自动曝光与曝光锁定

**现有问题：** 当前关闭 Manual controls 会同时启用自动曝光、自动对焦和自动白平衡，无法单独控制自动曝光。

**建议行为：**

- 提供独立的自动曝光开关。
- 支持自动测光后锁定曝光参数。
- 进入定量分析流程后，样品、标准品和校准拍摄应保持一致的相机参数。
- 明确显示当前处于自动曝光、锁定曝光还是完全手动模式。

**待确认：** 自动曝光是持续运行，还是仅测光一次后自动锁定。定量分析优先建议“自动测光后锁定”。

### 9. 默认对焦无穷远

**要求：**

- 手动焦距默认值从 `2.0 D` 改为 `0 D`。
- UI 将 `0 D` 明确显示为 `∞ / Infinity`。
- 可增加一键切换到无穷远的快捷操作。
- 不支持手动对焦的设备应禁用该控制且不崩溃。

**验收：** 支持手动对焦的设备默认采用无穷远；界面含义明确。

## P1：校准参数和默认数据

### 10. 波长参数默认内置并允许手动输入

**默认值：**

- R：622.5 nm
- G：522.5 nm
- B：462.5 nm

**要求：**

- 在界面中显示默认波长。
- 允许用户手动编辑 R/G/B 波长。
- 提供恢复默认值功能。
- 输入必须经过数字、合理范围和 R/G/B 顺序校验。
- 修改波长后清除依赖旧波长的下游分析结果。

**待确认：** `±2.5 nm` 公差是否也需要允许用户编辑。

### 11. Step 2 默认使用内置 true_spd.csv

**现有问题：** 当前未导入 CSV 时使用模拟 SPD，而项目中的真实 `true_spd.csv` 尚未打包进 Android 应用。

**要求：**

- 将经过确认的 `true_spd.csv` 打包为应用资源。
- Step 2 默认加载内置 CSV，而不是模拟 SPD。
- 保留用户导入自定义 CSV 并覆盖默认数据的功能。
- UI 明确显示当前使用“内置 true SPD”还是“用户导入文件”。
- 用户清除自定义文件后应恢复使用内置 CSV。
- 为内置 CSV 的解析和默认加载增加测试。

**验收：** 全新安装后，无需选择文件即可使用内置 CSV 完成 Step 2。

## P2：特殊布局

### 12. 半屏操作模式

**目标：** 当手机安装到检测装置后，即使前摄附近区域被遮挡，主要操作仍可在可见半屏完成。

**要求：**

- 提供手动开启和关闭半屏模式的入口。
- 半屏模式中重新排列主要按钮、设置项和分析操作。
- 保证所有关键操作都位于指定可见区域。
- 记住或明确显示当前布局模式。

**自动检测建议：**

- 可使用距离传感器作为遮挡判断的辅助信号。
- 不应完全依赖前摄画面判断，因为前后摄并发可能受硬件限制。
- 自动判断必须允许用户手动覆盖。

**待确认：**

- 可见区域是上半屏还是下半屏。
- 手机在装置中采用竖屏还是横屏。
- 自动进入模式所使用的传感器和触发条件。

## 开发辅助建议

### 14. Debug 模拟数据模式

为了在 Android 模拟器不支持真实 RAW 摄像头时测试完整流程，建议增加仅 Debug 构建可用的模拟模式：

- 提供固定的 R/G/B 定位光源数据。
- 提供 SPD 响应、样品和标准品模拟数据。
- 支持完整执行四步流程。
- 支持正常、噪声、过曝和校准失败场景。
- Release 构建不显示该入口。

该模式用于 UI 和业务逻辑开发，不能替代真机 RAW、曝光、焦距及真实光学系统验证。

## 实施与回滚规则

每次只处理一个小项目：

1. 修改前检查 Git 工作区，避免覆盖现有未提交内容。
2. 只修改当前项目所需文件。
3. 运行相关单元测试、编译检查和可执行的模拟器/真机验证。
4. 测试通过后创建独立 Git commit。
5. 在结果中记录提交哈希和验证方式。
6. 需要撤销时优先使用 `git revert <commit>`，保留完整历史。
